# mcp-calculator

一个基于 **MCP（Model Context Protocol）** 的计算器 Server，用 stdio 传输，对外暴露 4 个工具：

| 工具名     | 说明                    | 入参     |
| ---------- | ----------------------- | -------- |
| `add`      | 计算两个数字的和 a + b  | `a`, `b` |
| `subtract` | 计算两个数字的差 a - b  | `a`, `b` |
| `multiply` | 计算两个数字的积 a \* b | `a`, `b` |
| `divide`   | 计算两个数字的商 a / b  | `a`, `b` |
